# 🛡️ Windows Security Audit Tool

> Профессиональный инструмент аудита безопасности Windows, анализа защищённости и оценки соответствия требованиям информационной безопасности.

---

# 📖 О проекте

 Windows Security Audit Tool — это современный инструмент аудита безопасности операционных систем Windows, разработанный на PowerShell.

Проект предназначен для автоматизированной проверки защищённости рабочих станций и серверов, выявления потенциальных угроз, оценки соответствия международным стандартам информационной безопасности и формирования профессиональных отчётов с рекомендациями по устранению обнаруженных проблем.

WSA Tool может использоваться:

- специалистами по информационной безопасности;
- системными администраторами;
- инженерами SOC;
- аудиторами ИБ;
- специалистами по соответствию требованиям (Compliance);
- IT-подразделениями организаций любого масштаба.

# 🎯 Основные возможности

## 🔐 Аудит безопасности Windows

Проект автоматически выполняет комплексную проверку:

- Microsoft Defender
- Windows Firewall
- BitLocker
- Secure Boot
- TPM
- UAC
- Credential Guard
- Device Guard
- Virtualization Based Security (VBS)
- LSA Protection
- Windows Update
- Локальных политик безопасности
- Конфигурации операционной системы

---

## 🌐 Проверка сетевой безопасности

Выполняется анализ:

- SMB
- SMB Signing
- SMBv1
- WinRM
- RDP
- TLS
- SSL
- IPv6
- DNS
- Открытых портов
- Сетевых служб
- Сетевых интерфейсов

---

## 🏢 Проверка Active Directory

При работе в доменной инфраструктуре выполняется аудит:

- Password Policy
- Fine-Grained Password Policy
- Kerberos
- LDAP Signing
- SMB Signing
- LAPS
- Delegation
- Групповых политик (GPO)

## 🛡 Microsoft Defender

Проверяется состояние:

- Real-Time Protection
- Tamper Protection
- SmartScreen
- ASR Rules
- Controlled Folder Access
- Cloud Protection
- PUA Protection
- Исключений Defender
- Актуальности сигнатур

---

## 📦 Аудит установленного программного обеспечения

Автоматически анализируются:

- список установленного ПО;
- устаревшие версии;
- потенциально уязвимое программное обеспечение;
- соответствие известным CVE.

- Microsoft Office
- Google Chrome

- Mozilla Firefox
- Java

- WinRAR
- 7-Zip

- и другие популярные приложения.

# 📊 Проверка соответствия стандартам

WSA Tool поддерживает аудит по следующим требованиям:

- Microsoft Security Baselines
- CIS Benchmark
- DISA STIG
- NIST SP 800-53
- ISO/IEC 27001

---

# 📈 Security Score

После завершения проверки автоматически рассчитывается общий уровень защищённости системы.

Пример:

```text
Общий уровень безопасности: 92 / 100

Критические проблемы: 2

Высокий риск: 5

Средний риск: 11

Низкий риск: 7

Успешно пройдено проверок: 187
```

# 🚨 Анализ CVE

При обнаружении потенциально уязвимого ПО или небезопасной конфигурации WSA Tool отображает:

- CVE

- описание угрозы;
- рекомендации по устранению.

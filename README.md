# 🛡️ Windows Security Audit Pro (WSA Pro)

> Профессиональный инструмент аудита безопасности Windows, анализа защищённости и оценки соответствия требованиям информационной безопасности.

---

# 📖 О проекте

**Windows Security Audit Pro (WSA Pro)** — это современный инструмент аудита безопасности операционных систем Windows, разработанный на PowerShell.

Проект предназначен для автоматизированной проверки защищённости рабочих станций и серверов, выявления потенциальных угроз, оценки соответствия международным стандартам информационной безопасности и формирования профессиональных отчётов с рекомендациями по устранению обнаруженных проблем.

WSA Pro может использоваться:

- специалистами по информационной безопасности;
- системными администраторами;
- инженерами SOC;
- аудиторами ИБ;
- специалистами по соответствию требованиям (Compliance);
- IT-подразделениями организаций любого масштаба.

# 🚀 Быстрый запуск

Клонируйте репозиторий:

```powershell
git clone https://github.com/YOUR_USERNAME/WSA-Pro.git
```

Перейдите в каталог проекта:

```powershell
cd WSA-Pro
```

Запустите PowerShell от имени администратора.

Выполните:

```powershell
.\WSA.ps1
```

Создать HTML-отчёт:

```powershell
.\WSA.ps1 -Html
```

Экспортировать JSON:

```powershell
.\WSA.ps1 -ExportJson
```

Тихий режим:

```powershell
.\WSA.ps1 -Quiet
```

Запуск выбранных модулей:

```powershell
.\WSA.ps1 -Category Defender,Firewall
```
